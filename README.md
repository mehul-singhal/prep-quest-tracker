# ⚔️ Prep Quest Tracker

A gamified daily interview prep tracker built with React + Vite. Track DSA problems, system design, behavioral rounds, and more — with XP, streaks, spaced repetition revisits, and cross-device sync via GitHub Gist.

**Live app:** https://prep-quest-tracker.vercel.app

---

## Features

- **Daily Quest Cards** — each day has an objective, time budget, resources, and acceptance criteria (checkboxes). Clear all criteria to earn XP.
- **XP & Ranks** — earn XP by clearing days. Rank up as your total XP grows.
- **Streaks** — builds a day streak for every day you clear. One **Streak Freeze** per week protects a missed day.
- **Bonus Quest** — complete tomorrow's quest today for +20 bonus XP.
- **Catch-up** — missed past days still appear so you can clear them late.
- **DSA Revisit Queue** — every problem solved gets scheduled for spaced repetition revisits at +3, +10, and +25 days. Mark each as Hot (needed hints) or Cold (solved from memory).
- **Custom Tasks** — add ad-hoc tasks per day with category and duration. Incomplete tasks roll over to today.
- **Time Planner** — visual 7am–11pm timeline to block out your study sessions by category.
- **Day Notes** — attach a freeform note to any day (blockers, learnings, insights).
- **Progress Dashboard** — calendar heatmap, hours logged by category, streak history.
- **World Overview** — weeks are grouped into Worlds (themes). See XP earned vs available per World.
- **Weekly Report Export** — copy a structured summary of the week to paste into Claude for generating the next week's plan.
- **Cloud Sync** — GitHub Gist sync keeps data consistent across devices (phone + laptop) for free.
- **PWA** — installable on iPhone via Safari → Share → Add to Home Screen.

## How It Works

### Weekly Flow

1. **Import a week** — tap ＋ in the top bar, paste the week's JSON. Each week has 7 days with objectives, criteria, resources, and DSA problems.
2. **Work each day** — open the Today tab, check off acceptance criteria as you complete them.
3. **Log DSA revisits** — the DSA tab (🧩) shows problems due for revisit based on spaced repetition. Mark them done.
4. **End of week** — go to Settings → "Copy Weekly Report" → paste into Claude to generate next week's JSON.

### Week JSON Format

Weeks are generated by Claude (or written manually). The schema:

```json
{
  "weekNumber": 1,
  "world": 1,
  "theme": "Foundations",
  "days": [
    {
      "dayNumber": 1,
      "date": "2026-08-21",
      "label": "Thursday",
      "objective": "...",
      "timeBudgetMinutes": 180,
      "xp": 120,
      "resources": [{ "name": "...", "url": "..." }],
      "acceptanceCriteria": ["...", "..."]
    }
  ],
  "newProblemsSolved": [
    {
      "problem": "Two Sum",
      "solvedDate": "2026-08-21",
      "difficulty": "Easy",
      "topic": "Arrays"
    }
  ]
}
```

### Cross-Device Sync Setup

1. Go to [github.com](https://github.com) → Settings → Developer settings → Personal access tokens (classic)
2. Create a token with the `gist` scope
3. In the app: ⚙ Settings → Cloud Sync → paste token → Connect
4. Repeat on every device. Data syncs automatically within ~5 seconds of any change.

The Gist created is **private** — only visible to you when logged into your GitHub account.

## Data Storage

All data is stored in `localStorage` under the key `prepquesttracker_v1`. Use **Settings → Export JSON Backup** for a manual backup, and **Restore from backup** to load it back.
